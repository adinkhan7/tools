Two-sample means

Compare the mean of a continuous outcome between two arms (independent-samples t-test).

Cohen's benchmarks: 0.2 small · 0.5 medium · 0.8 large. Field experiments often target 0.15–0.3.
1 = equal arms. r = 2 puts twice as many in arm 2.

Methods note

Formulas and references 
n₁ = ((z₁₋α/₂ + z₁₋β) / d)² × (1 + 1/r),   n₂ = r × n₁            normal approximation (Cohen 1988)
n₁ ← n₁ + z₁₋α/₂² / 4                                            t-test correction (Guenther 1981): adds ≈1 per arm at α = 0.05
                                                                 and reproduces the noncentral-t solution to within one unit
d = |μ₁ − μ₂| / σ        r = n₂ / n₁        one-sided tests use z₁₋α in place of z₁₋α/₂
recruit = ⌈ n / (1 − a) ⌉  for expected attrition a
  1. Cohen J. (1988). Statistical Power Analysis for the Behavioral Sciences, 2nd ed. Erlbaum.
  2. Guenther W.C. (1981). Sample size formulas for normal theory t tests. The American Statistician 35(4): 243–244.

Two proportions

Compare a binary outcome (adoption, pass rate, conversion) between two arms.

As a fraction, 0–1

Methods note

Formulas and references 
Pooled variance (shown as the main result; matches Stata `power twoproportions` and R `power.prop.test`):
n₁ = [ z₁₋α/₂ √((1 + 1/r) p̄ q̄) + z₁₋β √(p₁q₁ + p₂q₂ / r) ]² / (p₁ − p₂)²,   p̄ = (p₁ + r p₂) / (1 + r),  q = 1 − p

Unpooled variance (shown in the result card):
n₁ = (z₁₋α/₂ + z₁₋β)² (p₁q₁ + p₂q₂ / r) / (p₁ − p₂)²

No continuity correction is applied (Fleiss' correction adds roughly 1/|p₁ − p₂| per arm and is
conservative). n₂ = r × n₁.  recruit = ⌈ n / (1 − a) ⌉.
  1. Fleiss J.L., Levin B., Paik M.C. (2003). Statistical Methods for Rates and Proportions, 3rd ed. Wiley.
  2. Cohen J. (1988). Statistical Power Analysis for the Behavioral Sciences, 2nd ed.

Cluster RCT

Randomise villages, schools or clinics instead of individuals; inflate for within-cluster correlation.

Typical: 0.01–0.05 health, 0.05–0.2 education, village-level economic outcomes
SD of cluster size ÷ mean size; leave blank for equal clusters

Methods note

Formulas and references 
DE = 1 + (m − 1) ρ                               equal cluster sizes (Donner & Klar 2000)
DE = 1 + ((1 + CV²) m − 1) ρ                     unequal cluster sizes; CV = SD(size)/mean(size)
                                                 (Eldridge, Ashby & Kerry 2006; Hayes & Moulton 2017)
n_cluster = ⌈ n_individual × DE ⌉                n_individual from the means or proportions formula above
k = ⌈ n_cluster / m ⌉ clusters per arm;          analysed per arm = k × m

Clusters fixed at k per arm (Hemming et al. 2011):
m ≥ n (1 − ρ) / (k − n ρ (1 + CV²))             no cluster size suffices when k ≤ n ρ (1 + CV²)

Attrition: recruit ⌈ m / (1 − a) ⌉ per cluster so m remain; the number of clusters is unchanged.
With fewer than ~15 clusters per arm, add 1–2 clusters per arm or use a t-distribution with
k₁ + k₂ − 2 degrees of freedom; the normal approximation is optimistic.
  1. Donner A., Klar N. (2000). Design and Analysis of Cluster Randomization Trials in Health Research. Arnold.
  2. Hayes R.J., Moulton L.H. (2017). Cluster Randomised Trials, 2nd ed. Chapman & Hall/CRC.
  3. Hemming K., Girling A.J., Sitch A.J., Marsh J., Lilford R.J. (2011). Sample size calculations for cluster randomised controlled trials with a fixed number of clusters. BMC Medical Research Methodology 11: 102.
  4. Eldridge S.M., Ashby D., Kerry S. (2006). Sample size for cluster randomized trials: effect of coefficient of variation of cluster size and analysis method. International Journal of Epidemiology 35(5): 1292–1300.

Minimum detectable effect

The budget fixes the sample. What is the smallest effect you can reliably detect?

Used to express the MDE in percentage points

Methods note

Formulas and references 
n_analysed = ⌊ n_recruited × (1 − a) ⌋            DE = 1 + (m − 1) ρ
d_MDE = (z₁₋α/₂ + z₁₋β) × √( (1 + 1/r) / ( n_analysed / DE − z₁₋α/₂² / 4 ) )
        (the means formula with Guenther's t-correction, solved for d)

Binary outcome, control proportion p₁, unpooled variance:
δ² = K [ p₁q₁ + (p₁ + δ)(1 − p₁ − δ) / r ],   K = (z₁₋α/₂ + z₁₋β)² DE / n_analysed
which is quadratic in δ:  (1 + K/r) δ² − (K/r)(q₁ − p₁) δ − K p₁q₁ (1 + 1/r) = 0  →  positive root.
For a decrease, replace (q₁ − p₁) by (p₁ − q₁). MDE in percentage points = 100 δ.
  1. Bloom H.S. (1995). Minimum detectable effects: a simple way to report the statistical power of experimental designs. Evaluation Review 19(5): 547–556.
  2. Hayes R.J., Moulton L.H. (2017). Cluster Randomised Trials, 2nd ed.

Questions people ask

Why does the calculator give 64 per arm when the textbook formula gives 63?

The textbook formula n = 2((zα + zβ)/d)² uses the normal distribution and gives 62.8, rounded up to 63, for d = 0.5, α = 0.05 two-sided and 80% power. A two-sample t-test has slightly less power because the SD is estimated, so we add Guenther's correction of zα²/4 (about one participant per arm): 63.75, rounded up to 64. This matches the exact noncentral-t solution used by Stata's power twomeans and R's pwr.t.test.

How does the intracluster correlation (ICC) change the sample size?

When whole clusters are randomised, people within a cluster are more alike than people from different clusters, so each additional person adds less information. The design effect DE = 1 + (m − 1)·ICC inflates the individual-level sample size. With ICC = 0.05 and 20 people per cluster, DE = 1.95, so 64 per arm becomes 125 per arm, or 7 clusters of 20 per arm.

Should attrition be applied before or after the design effect?

Compute the analysed sample size first (including the design effect), then divide by 1 − attrition to get the number to recruit. In a cluster trial this calculator keeps the number of clusters fixed and over-recruits within each cluster: with 20 analysed per cluster and 20% attrition, recruit 25 per cluster.

What is the finite population correction in the survey calculator?

The basic survey formula n₀ = z²p(1 − p)/e² assumes an effectively infinite population: for p = 0.5, a ±5 point margin and 95% confidence it gives 384.2, so 385 respondents. If the population is small, n = n₀/(1 + (n₀ − 1)/N) reduces the sample; for N = 2,000 the requirement falls to 323. The correction matters only when the sample exceeds about 5% of the population.
